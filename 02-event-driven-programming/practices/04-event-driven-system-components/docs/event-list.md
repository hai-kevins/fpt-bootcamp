# Event List

| Signal | Producer | Consumer | Meaning |
|---|---|---|---|
| `APP_START_SIG` | User/System | App | Start application |
| `DISPLAY_UPDATE_SIG` | App | Display | Refresh output |
| `SENSOR_DATA_SIG` | Sensor | Display/Diagnostic | New sample |
| `LINK_ERROR_SIG` | Data-Link | Diagnostic | Retry limit exceeded |
